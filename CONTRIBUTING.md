# Contributing to BreakDial

## Licence

All code in this repository is licensed under `Apache-2.0`
(Copyright 2026 Aleks Linde). By contributing, you agree your
contribution is made under the same licence.

## New files

Every new source file must start with this header:

```
// SPDX-FileCopyrightText: 2026 Aleks Linde
// SPDX-License-Identifier: Apache-2.0
```

## DCO sign-off

Sign off every commit to certify you may submit it under the project
licence (Developer Certificate of Origin):

```bash
git commit -s -m "describe the change"
```

This adds a `Signed-off-by:` trailer. Pull requests without sign-off
will not be merged.
